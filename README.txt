DESCRIPTION
-----------
This folder contains the figures used for Experiment 3 of the Deep Learning Laboratory.
The experiment uses the CIFAR-10 dataset and covers convolution, kernel-size comparison,
hyperparameters, feature-map visualization, pooling, CNN training and model evaluation.

FIGURES
-------
1. sample_images.png
   Ten sample CIFAR-10 images used for dataset exploration.

2. class_distribution.png
   Distribution of the CIFAR-10 classes in the dataset.

3. kernel_size_feature_maps.png
   Feature-map comparison for 3x3, 5x5 and 7x7 convolution kernels.

4. feature_maps_first_conv.png
   Feature maps obtained after the first convolution layer.

5. pooling_feature_maps.png
   Feature-map comparison for different pooling operations.

6. pooling_accuracy_comparison.png
   Accuracy comparison between Max Pooling and Average Pooling.

7. training_accuracy.png
   Training accuracy plotted against epoch for the CNN model.

8. validation_accuracy.png
   Validation accuracy plotted against epoch for the CNN model.

9. training_loss.png
   Training loss plotted against epoch for the CNN model.

10. validation_loss.png
    Validation loss plotted against epoch for the CNN model.

11. confusion_matrix.png
    Confusion matrix of the trained CNN on the CIFAR-10 test set.

12. classification_metrics.png
    Class-wise precision, recall and F1-score comparison.

13. relu_sigmoid_training_accuracy.png
    Training-accuracy comparison between ReLU and Sigmoid activation functions.

14. relu_sigmoid_validation_accuracy.png
    Validation-accuracy comparison between ReLU and Sigmoid activation functions.

15. sample_input.png
    Sample input image used for convolution/feature-map visualization.

16. pooling_feature_maps.png
    Feature-map visualization associated with the pooling comparison.
